# 🎬 Netflix User Engagement & Churn Analysis

## 📌 Overview

This project is an end-to-end analytics case study focused on understanding user engagement and customer churn for a subscription-based streaming platform. It combines data analysis, product analytics, business intelligence, and data science concepts to transform raw user data into actionable business insights.

The project follows a business-first approach where every analysis begins with a product question, is supported by statistical reasoning, implemented using NumPy, and concludes with data-driven recommendations.

---

## 🎯 Business Problem

For subscription-based businesses such as Netflix, sustained user engagement is directly linked to customer retention and revenue growth. The objective of this project is to identify the factors influencing user engagement, understand why users churn, and uncover opportunities to improve customer retention through data-driven decision making.

---

## 🚀 Key Objectives

* **Analyze** user engagement across different customer segments.
* **Identify** behavioral patterns associated with customer churn.
* **Evaluate** the impact of recommendations, subscriptions, devices, and demographics on user engagement.
* **Generate** business insights and actionable recommendations.
* **Build** a professional analytics workflow using NumPy from data ingestion to business interpretation.

---

## 🔍 Methodology - The Science behind the Analysis
This analysis is built on a structured dataset containing user demographics, subscription information, viewing behavior, recommendation interactions, account activity, and churn status. These attributes provide a comprehensive view of how users engage with the platform and enable the exploration of factors that influence customer retention.

The project follows a systematic analytics workflow beginning with data ingestion and validation to ensure data quality before any analysis is performed. The dataset is then prepared for exploration, where user behavior, engagement patterns, subscription trends, and churn indicators are examined using statistical analysis and business-driven KPIs.

All data manipulation and numerical computation are performed using **NumPy**, emphasizing efficient vectorized operations and a strong understanding of analytical fundamentals. **Matplotlib** is used to create visualizations that communicate trends and insights effectively. As the project progresses, statistical techniques and machine learning models will be implemented to explain user behavior, predict churn, and generate actionable business recommendations.
